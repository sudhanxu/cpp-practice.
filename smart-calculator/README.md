
# Smart Calculator

A menu-driven calculator application developed using C++.
This project demonstrates fundamental programming concepts
through a simple and interactive command-line application.

## Features

- Addition, subtraction, multiplication and division
- Modulus calculations
- Power calculations
- Square root calculations
- Percentage calculations
- Continuous calculations
- Input validation
- Division-by-zero protection
- Formatted numerical results

## Technologies Used

- C++
- Standard Template Library (STL)
- GCC Compiler
- Git and GitHub

## How to Run

Clone the repository:

    git clone https://github.com/sudhanxu/cpp-practice.git

Navigate to the project:

    cd cpp-practice/smart-calculator

Compile:

    g++ -std=c++17 -Wall -Wextra -pedantic calc.cpp -o calculator

Run:

    ./calculator

## Concepts Practiced

- Functions
- Loops
- Conditional statements
- Switch statements
- User input and output
- Mathematical operations
- Error handling
